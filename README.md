# Tax Strategy Calculator

This project is a modern tax calculator designed to help you strategise your investments and savings effectively. It is built as a single-page application and the repository now contains both the original React source code and the static assets generated by the build process. You can run the app locally or rebuild it at any time.

## Goals

- Provide an easy-to-use interface for calculating tax strategies.
- Demonstrate a simple React based deployment using static files.

## Installation

1. Ensure you have **Node.js** installed (recommend v18 or later).
2. Install dependencies using **npm** (or `yarn` if preferred):
   ```bash
   npm install
   ```

To run the test suite:

```bash
npm test
```

## Development Server

To run the application in development mode:

```bash
npm start
```

This starts a local server and opens the app in your default browser. Any saved changes will automatically reload the page.

## Build Static Assets

Create a production build using the standard Create React App workflow:

```bash
npm run build
```

The command runs `react-scripts build` and outputs the optimized files to the `build/` directory.

## Deployment

Pushes to the `main` branch automatically build and deploy the latest version of the app to the `gh-pages` branch using GitHub Actions. The workflow installs dependencies, runs the production build, and publishes the contents of the `build/` directory with [peaceiris/actions-gh-pages](https://github.com/peaceiris/actions-gh-pages).

## Design Guidelines & Coding Standards

- Follows React best practices with functional components and hooks.
- Code should be formatted using [Prettier](https://prettier.io/) and follow common linting rules (such as ESLint with the Airbnb style guide).
- Keep components small and focused on a single responsibility.
